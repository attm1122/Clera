# Clera

Clera is a native iPhone app for tracking skin progress over time with guided check-ins, routine logging, and clear visual comparisons.

## Stack

- SwiftUI
- Observation
- XcodeGen
- Xcode 26+
- iOS 17+

## Getting started

```bash
xcodegen generate
open Clera.xcodeproj
```

## Current scope

This first foundation includes:

- Brand-aligned native iOS shell
- Onboarding flow
- Home, Progress, Routine, and Profile tabs
- Sample progress data and weekly summary cards
- Compare experience scaffold
- Settings and reminders foundation
